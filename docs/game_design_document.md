# PyRogue ゲームデザインドキュメント

**補助資料（仕様の正本: [`SPEC.md`](../SPEC.md)）**

この文書は、リポジトリ直下の `SPEC.md` を補足するゲームデザイン資料です。
PyRogueは、Rogue 5.4の緊張感を小さなテキストローグライクとして再現します。

## コア体験

プレイヤーは未知のダンジョンを探索し、限られた食料と装備を使って26階を目指します。
死亡は永続的で、勝利条件はAmulet of Yendorを持って地上へ戻ることです。26階へ到達する
だけでは勝利になりません。

1. 部屋と通路を探索する。
2. 視界内のモンスターやアイテムに対応する。
3. 食料、HP、装備、インベントリを管理する。
4. 階段で階を移動し、Amuletを回収する。
5. 地上へ戻るか、死因とスコアを確認してゲームを終える。

## ダンジョン

- 全26階。通常階は矩形の部屋とL字通路で構成する。
- 7、13、19階は迷路階とする。
- 通常階には上り階段と下り階段を置き、26階には下り階段を置かない。
- 階段は必ず歩行可能な領域に接続する。
- 一度生成した階の地形、アイテム、モンスター、トラップは階移動後も保持する。
- プレイヤーは現在の視界だけを完全に見られ、過去に探索した地形は記憶として表示する。

## プレイヤーと戦闘

プレイヤーには経験値、レベル、HP、攻撃力、防御力、武器、防具、ゴールドを持たせます。
戦闘は1ターン単位で、隣接した相手を攻撃します。攻撃判定とダメージはRogue系の
d20・AC・武器ダイスを基準にし、独自のクリティカル補正や単純な攻防差分は追加しません。
プレイヤーの行動後に、視界内のモンスターが行動します。

## モンスター

主要なA-Zモンスターを定義し、論理ID、名前、出現階、レベル、HP、攻撃、ACをゲームデータとして
管理します。表示記号への変換は `pyrogue.presentation.display_renderer` が担当します。モンスターはプレイヤーを視認すると1マスずつ追跡し、隣接時は攻撃します。
視界外のモンスター情報は表示しません。

## アイテムとトラップ

アイテム種別は武器、防具、食料、ポーション、巻物、杖、指輪、ゴールド、Amuletです。
ポーション、巻物、杖、指輪は未識別の外見を持ち、使用や識別で正体が判明します。装備、
解除、投擲、消費、拾う、落とすをインベントリから行えます。呪われた装備は装備中に外せません。
インベントリ上限は23個です。

原作系の落とし穴、熊罠、テレポート、毒矢、睡眠ガス、錆、謎の罠、矢罠を扱います。
`s`で周囲を探索して罠を発見し、罠に入ると効果が発生します。独自の罠解除難易度や解除
ミニゲームはありません。

## 飢えと終了

食料は時間資源です。ターンごとに消費し、残量に応じて警告を表示します。食料切れ後も
時間が進むと飢餓で死亡します。満腹度による攻撃力などのカスタム戦闘ペナルティはありません。

死亡状態と勝利状態は終端状態です。勝利・死亡時には最深階を表示し、これは現在位置を表す
`current_floor` ではなく到達記録の `deepest_floor` を使います。死亡時には死因、キル数、ゴールド、
スコアも保存・表示し、死亡時はセーブを削除して死亡セーブからの再開を拒否します。CLIとGUIは同じ後処理を使います。

## 入力

| 入力 | 動作 |
| --- | --- |
| `h` `j` `k` `l` `y` `u` `b` `n` | 8方向移動 |
| `.` | 待機 |
| `a` / `f` | 隣接攻撃 |
| `,` | 足元のアイテムを拾う |
| `d` | アイテムを落とす |
| `e` / `q` / `r` | 食べる / 飲む / 読む |
| `w` / `W` / `T` | 武器を装備 / 防具を装備 / 防具を外す |
| `P` / `R` | 指輪を装備 / 外す |
| `t` / `z` | 投げる / 杖を使う |
| `s` / `^` | 探索 / 足元の罠を識別 |
| `<` / `>` | 上る / 下りる |
| `i` / `@` / `?` / `/` | インベントリ / 状態 / ヘルプ / アイテム識別 |
| `S` / `Q` | 保存 / 終了 |

入力が衝突する場合、移動と探索などを同じキーに割り当てません。

## 実装上の制約

canonicalなゲーム状態はTCODのConsole、色、画像、タイルオブジェクトを参照しません。
MP、魔法職、NPC、明暗、オート探索、重量制限、独自状態異常、逃走・分裂・特殊部屋など、
原作にない拡張は0.3.0の仕様対象外です。
